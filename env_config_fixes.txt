## #366 - Makefile fmt-check Target

Add to Makefile:

.PHONY: fmt fmt-check

fmt:
	cargo fmt --all

fmt-check:
	cargo fmt --all -- --check

Add to README.md Contributing section:

### Code Formatting

Run `make fmt` to auto-format all Rust code according to rustfmt.toml.
Run `make fmt-check` locally before committing to catch formatting drift.
CI will reject commits with formatting violations.
