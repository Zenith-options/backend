### Verifying OpenAPI Consistency

Before opening a PR that modifies routes:

```bash
make check-openapi
```

This command:
1. Regenerates the OpenAPI spec from route definitions
2. Verifies openapi/openapi.yaml matches server routes
3. Regenerates sdk/typescript/src/zenith.ts
4. Fails with diff if spec or SDK is out of sync

## #359 - Error Catalogue Verification

Update scripts/generate-error-catalogue.mjs to add --check mode:

```javascript
// Add to generate-error-catalogue.mjs
const checkMode = process.argv.includes('--check');

// ... generate catalogue ...

if (checkMode) {
  const existing = fs.readFileSync('docs/error-catalogue.md', 'utf-8');
  if (existing !== generated) {
    console.error('ERROR: docs/error-catalogue.md is out of sync with docs/error-codes.json');
    console.error('Run: npm run generate-error-catalogue');
    process.exit(1);
  }
  console.log('✓ Error catalogue is in sync');
} else {
  fs.writeFileSync('docs/error-catalogue.md', generated);
}
```

Add to Makefile:

.PHONY: check-error-catalogue

## #357 - Makefile Setup Target

Add/update in Makefile:

.PHONY: setup

setup:
	@echo "Setting up local development environment..."
	@if [ ! -f .env ]; then \
		echo "Creating .env from .env.example..."; \
		cp .env.example .env; \
		echo "✓ Created .env"; \
		echo "⚠️  Review .env and update any secrets/configuration"; \
	else \
		echo ".env already exists, skipping..."; \
	fi
	@if [ ! -d .sqlx ]; then \
		echo "ERROR: .sqlx directory not found"; \
		echo "This directory contains SQLx offline query cache"; \
		echo "It should be committed to the repository"; \
		exit 1; \
	else \
		echo "✓ SQLx offline cache found"; \
	fi
	@echo "Setup complete!"
	@echo "Next steps:"
	@echo "  1. Update .env with your configuration"
	@echo "  2. Run: cargo build"
	@echo "  3. Run: cargo test"

Document in README.md:

## Local Development Setup

```bash
make setup     # Copies .env.example to .env, checks SQLx cache
cargo build    # Build the project
cargo test     # Run tests
```

The setup target:
- Creates .env from .env.example if it doesn't exist
- Verifies .sqlx offline cache is present
- Does NOT overwrite an existing .env
